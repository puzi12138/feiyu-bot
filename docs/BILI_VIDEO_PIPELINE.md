# B站视频画面分析与证据边界

自动浏览、手动视频链接分析和专门音画研究，在需要新的画面分析时优先共用 `dsh-video-storyboard`。字幕足以回答的路径仍可直接使用字幕，不强制下载视频。此文描述源码行为，不代表新安装环境已启用自动业务或完成真实视频验收。

## 接入方式

| 入口 | 新画面处理 | 保留的流程 |
| --- | --- | --- |
| B站插件自动浏览、手动或链接分析 | 每个可用片段调用共享桥，最多9帧、1张分镜图 | 字幕策略、BV锁、成功缓存、已处理去重、显式重看和原媒体回退 |
| 专门音画研究 | 共享桥输出最多18帧、2张分镜图，再交现有视觉服务 | 真实音轨ASR、旧分析缓存、原阅读及手账路径 |
| 自动私人手账 | 不把分镜摘要直接改写为字幕或作者原话 | `dsh-bili-humanism` 的原来源链、A1/A2证据检查和推荐条件 |

共享桥位于 [BiliStoryboard.py](../scripts/BiliStoryboard.py)。B站插件的 [storyboard_bridge.py](../plugins/astrbot_plugin_bilibili_ai_bot/core/storyboard_bridge.py) 固定加载这个独立模块，不初始化另一插件。音画研究入口位于 [video_media.py](../plugins/feiyu_steward/video_media.py)。

桥接层只接收所属目录内的本地媒体，独立创建临时目录，校验输入来源、PNG和清单；固定使用本地Node、FFmpeg及FFprobe，并关闭分镜工具自带转录。它不接收浏览器Cookie、模型凭据或远程视频地址。原部署使用 `dsh-video-storyboard` v0.7.5，并对其命令行入口使用本地兼容补丁，将旧的分镜数量参数映射为上述帧数和图片上限。新版可自适应排布，不保证固定九宫格或一定输出两张图片。许可及来源见 [来源锁](../upstream/DEPENDENCIES.lock.json) 与 [组件声明](../THIRD_PARTY_NOTICES.md)。新环境须单独核对工具版本与安装路径。

迁移时，先取得并安装依赖，再将 `scripts/` 和插件映射到各自运行目录。源码中的安装根路径是需要适配的部署约定；不要直接从仓库根目录导入插件，也不要关闭所属目录和来源校验以绕过安装问题。具体准备见 [重新安装与配置](SETUP.md)。

## 音频、缓存与手账

- 分镜工具负责画面抽样，音频仍由原真实音轨ASR处理：短视频使用可用音轨，长视频抽取开头、中段和结尾，合计最多600秒；不等于理解完整配乐、语气或全部对白。
- 有效旧缓存继续沿用原采样方法和范围；新视觉缓存校验源文件元数据、图片及清单哈希。变化或不完整的缓存保留并报告，不自动覆盖未知结果。
- 自动手账继续原来源和证据链。分镜图及视觉摘要不是字幕、作者逐字原话或已写入笔记的证明。
- 成功自动观看后的推荐理由可以使用同次新生成的公开媒体分析，但必须核对视频身份、时间、分析代次、摘要散列、摘要截断内容和实际分镜覆盖，并与观看记录及视频缓存相互匹配。缓存复用不冒充新分析，缺失或不匹配时回退原文字流程，不补看旧视频。该公开摘要可能混合抽样画面、字幕、标签、公开评论和检索内容，不是纯画面描述或作者逐字原话；私人笔记和个人评分理由不作为公开媒体来源。
- 专门音画研究的新分镜结果在写手账前核对证据时间与已记录取帧点、音频起点或来源文字定位；不匹配时保留总结但不写笔记。时间匹配不是语义正确性或精确解码帧时间的证明。
- 各入口保留原有缓存与任务边界，没有新增跨入口的全局去重服务；不能保证不同入口只下载或只调用模型一次。既有发送保护和结果不明时的阻断保持。

## 覆盖说明与失败处理

纯分镜、分镜混合原媒体回退、全部原媒体回退分别记录实际方法。覆盖计数的分母是本次成功取得的可用片段，不代表全片连续观看；实际帧数、排布和采样范围以输出清单为准。中点取帧记录近似定位，不伪称精确解码帧时间。分镜的音频能量信息不等于音频转写或理解。

原生视频分析在分镜失败时保留原媒体直读或截帧回退。取消后不继续启动新回退；并行音画分支会回收本地任务，但不能据此保证已发给远端的请求撤回。本次未增加模型重试器，也不回放历史任务。

## 验证范围

原生专项检查27项通过；音画研究检查33项通过，2项实际符号链接检查受Windows权限限制跳过，其替代路径解析检查通过；手账覆盖说明的6个分支检查通过。旧版共享工具处理本地合成视频时曾得到一张九格和两张九格输出。v0.7.5兼容层经本地合成视频验证，并在原部署的正常后台周期完成过真实视频分镜分析；三源公开媒体来源交接经过隔离检查与模拟链验证。

上述各项验证覆盖不同版本和路径，不能互相替代；真实视频的自然分镜分析不等于完整音频理解、手账写入或平台推荐发送成功，也不等于从公开仓库完成重建验证。旧模型路由套件的3项失败及1项错误在未修改基线中同样存在，未计入通过结论。最长45分钟的视频准入限制不保证每条视频都能在分镜处理预算内完成。

## 自动浏览来源与连接

兴趣浏览先完整分页获取当前账号的关注列表：每页最多50项、最多20页，全部最多1000项。读取使用单个会话，整次分页有15秒总预算、每页最多10秒；遇到特定未取得响应的瞬时连接错误时，全列表最多允许一次应用层同页重连，间隔0.25秒并计入原预算。证书及其他SSL错误、超时、取消、HTTP或API拒绝，以及响应返回后的失败不在该例外内；底层库既有行为不由该上限保证。身份、时段、暂停和完整性检查保持，不能使用不完整的列表。

仍在列表中的特别关注优先，其余每轮从当前关注中随机选取有限数量的UP，只看各UP最新的未看视频，不承诺有限轮覆盖所有关注。候选不足时最多使用一组有限的相关搜索词，词来自当前关注关联的合格分析记忆标签或本轮视频元数据；不额外调用模型选词，也不扩大到泛热门流。原部署按60分钟持久节拍、当地白天闲时运行；具体启用状态、授权与时段以新环境配置为准。关注导入是单次单独授权的维护工作，不代表已经启用自动关注。
