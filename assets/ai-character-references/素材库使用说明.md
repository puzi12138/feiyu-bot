# 九位AI角色服装素材库使用说明

本库保留旧数字编号归档，新增服装为可选参考；原漫画及生产默认角色映射不变。当前完成数量和可用路径以[角色素材索引](角色素材索引.json)与[角色素材总览](角色素材总览.md)为准，不把计划或待验收图片当成成品。

## 选取素材

指定角色、服装、形态即可，例如“肥鱼，正常版，幻想主题礼装”或“Gemini，Q版，日常休闲装”。三个服装类别为日常休闲装、外出机能装、幻想主题礼装；每个角色有各自独立的设计名称。

后续程序可读取索引的`characters → outfits → images`，按角色与服装的`id`或`name`定位，只使用`status=accepted`的图片。图片路径相对于本索引所在目录；索引中的尺寸为实际原生尺寸，不能把建议尺寸当作实际输出。

也可使用维护工作区的只读检索工具：

```powershell
python -B scripts/find_character_outfit.py --character 肥鱼 --outfit 幻想主题礼装 --form 正常版
python -B scripts/find_character_outfit.py --character Gemini --outfit 日常休闲装 --form Q版
```

工具返回完整路径并核对SHA-256。尚未验收、文件缺失或散列不匹配时拒绝返回，不自动替换成另一套衣服。审阅包解压后可通过`--index 完整索引路径`检索包内素材，不依赖原机器绝对路径。

## 目录与验收

每个角色包含“原始参考”“正常版”“Q版”“设计对照”和角色说明。正常版与Q版同套服装同名，分别保存；两种比例为分别绘制，不是机械缩小。对照图仅从已验收立绘合成，左侧正常版、右侧Q版；更新排版时保留旧版本。

新立绘优先采用内置绘图工具的原生透明PNG。透明素材应在白色或棋盘底上查看；某些查看器显示零alpha像素的底色，不代表实际合成背景。不能用阈值抠图破坏发丝、龙翼、裙边和配件。具体背景及尺寸见每张记录。

## 公开归档与版本

公开包保留原始参考、54张已验收新立绘、当前及历史对照图、索引和角色说明。仅索引中`status=accepted`且散列匹配的图片是当前成品；`Kimi/制作历史/`和无`-v2`后缀的旧对照图用于版本对照。

完整提示词、生成意图、会话标识和本机制作工作目录不公开。索引的本机路径已转为相对路径，工具产物标识已移除；图片文件原字节、透明通道、来源元数据及验收散列保持。

本库未接入自动换装、漫画投稿或定时任务，不改变任何发布授权或业务开关。
