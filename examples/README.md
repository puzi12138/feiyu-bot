# 本地配置准备模板

`deployment.template.json` 是人工重建清单，不会被机器人自动加载，也不包含账号和授权。请按各插件的 `_conf_schema.json` 与实际部署版本生成自己的配置。

- 身份字段为空，源码中原安装的账号已替换为 `0`；`0` 不是可用账号。恢复时需要逐项设置主人、机器人、好友和群的权限，不能把多个角色继续设为同一个占位值。
- 凭据请只存放在本机被忽略的配置文件或受支持的环境变量中，不能写回源码。不要提交真实 `.env`、Cookie、授权 JSON、数据库或登录态。
- 自动外发功能初次迁移时保持关闭或未授权。只有在使用者明确配置后才考虑开启，旧的故障恢复、排队、回执和账本不能由空模板伪造。
- 私人人格投影、个人偏好和角色素材清单未导出；需要时在本地重新创建。不要把占位提示词当作原来的私人设定。
- 原生桥保留完整性校验。重新配置后须审核整个文件集合并生成匹配清单，不要通过删除哈希校验来启动。

导出源码未做新的部署验收。本模板不保证单独填写这些字段即可启动全部组件。
